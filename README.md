## 🚀 Featured Projects

### 01. Banking Support AI Platform

**Generative AI | RAG | LangChain | LangGraph | Vector Search**

An AI-powered banking support platform designed to deliver policy-grounded responses using retrieval-augmented generation.

- Built document ingestion and preprocessing pipelines for banking policy knowledge.
- Implemented semantic retrieval using ChromaDB and Hugging Face embeddings.
- Developed grounded LLM generation with source citations and abstention handling.
- Implemented retrieval and generation evaluation workflows.
- Designed the architecture around modular, testable components.

**Repository:** [Banking-Support-AI](https://github.com/mbewustanley/Banking-Support-AI)

### 02. Customer Support Classification

**PyTorch | Hugging Face | Transformers | NLP | MLOps**

An end-to-end NLP classification pipeline using the Banking77 dataset to classify customer support queries into 77 banking intents.

- Fine-tuned DistilBERT for multi-class intent classification.
- Implemented reproducible preprocessing and data validation.
- Developed modular training and evaluation workflows.
- Evaluated performance using accuracy, precision, recall and macro F1.
- Achieved **0.8606 validation macro F1** during model training.

**Repository:** [Customer-Support.TC](https://github.com/mbewustanley/Customer-Support.TC)

### 03. YouTube Insights

**Machine Learning | Flask | Docker | AWS | MLflow | DVC**

An end-to-end machine learning application built around an automated ML pipeline and deployment workflow.

- Developed a modular ML pipeline covering ingestion, preprocessing, training, evaluation and model pushing.
- Integrated MLflow for experiment tracking and model registry.
- Used DVC to organize and manage pipeline stages.
- Containerized the application with Docker.
- Worked with AWS EC2 and Amazon ECR for cloud infrastructure and image management.

**Repository:** [YouTube Insights](https://github.com/mbewustanley/Youtube-Insights)

### 04. Loan Default Prediction

**Machine Learning | Scikit-learn | Model Evaluation**

A machine learning classification project focused on predicting loan default risk.

- Developed a Random Forest classification model.
- Evaluated model performance using accuracy, F1 score and ROC-AUC.
- Explored the challenges of classification under imbalanced outcomes.

**Repository:** [ML MLOps Loan Default](https://github.com/mbewustanley/mlops-loan-default)
